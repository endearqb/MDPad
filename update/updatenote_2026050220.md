# 恢复表格选区浮动菜单

## 变更摘要
- 恢复 Markdown 表格单元格、行、列和整表选区时的专用浮动菜单。
- 普通文本 BubbleMenu 继续避开 `CellSelection`，表格操作由独立菜单承载。

## 实现说明
- 新增 `TableActionMenu` TipTap 扩展，复用现有 `FloatMenuView` 和 `.ProseMirror-fm*` 样式。
- 菜单根据当前表格选区类型显示不同操作：
  - 整表：对齐、切换表头行/列、删除表格。
  - 整行：插入行、对齐、删除行。
  - 整列：插入列、对齐、删除列。
  - 单元格/多单元格：合并、拆分、对齐。
- 菜单只在可编辑态显示，只读态不显示。

## 验证
- 新增单测覆盖 cell / row / column / table 菜单与只读态。
- 保留文本 BubbleMenu 对 `CellSelection` 的隐藏断言，避免两个菜单同时出现。
