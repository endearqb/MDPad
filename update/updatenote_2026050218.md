# Markdown 表格辅助选中手柄

## 变更摘要
- 为 Markdown 富文本编辑器新增表格辅助选中手柄。
- 表格悬停时显示列、行和整表角手柄。
- 点击列手柄选中整列，点击行手柄选中整行，点击左上角手柄选中整表。

## 实现说明
- 新增 `TableSelectionGrip` TipTap 扩展，通过 ProseMirror Decoration 渲染手柄。
- 复用现有 `tableSelection.ts` 的行、列、整表选择 helper。
- 复用现有 `.ProseMirror-table-grip-*` 样式体系，仅补充 hover 显示与按钮重置规则。
- 保留现有 `.selectedCell` 高亮和列宽拖拽能力，不改变 Markdown 序列化结果。

## 验证
- 新增单测覆盖列、行、整表手柄点击后的 `CellSelection`。
