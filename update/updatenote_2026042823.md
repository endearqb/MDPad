# v0.2.11 发布记录

## Summary
- 本次发布聚焦编辑器内核迁移：MDPad 已从 Tiptap 2 + `tiptap-markdown` 切换到 Tiptap 3 + 官方 `@tiptap/markdown`。
- 当前发布版本为 `0.2.11`，安装包为 `MDPad_0.2.11_x64-setup.exe`。
- GitHub Release 使用 `docs/release-notes-v0.2.11.md` 作为发布说明。

## Editor Core
- 直接依赖的 `@tiptap/*` 包统一到 `3.22.4`，React 保持 18。
- 删除第三方 `tiptap-markdown`，改用官方 `@tiptap/markdown@3.22.4`。
- Markdown 文档初始化与外部同步使用 `contentType: "markdown"`。
- 保存同步改为 `editor.getMarkdown()`，再与 front matter 拼接。
- BubbleMenu 适配 Tiptap 3 菜单入口与 Floating UI 配置。
- `StarterKit` 显式关闭内置 Link，避免与 MDPad 自定义 Link 扩展重复注册。

## Paste and Table Behavior
- 富文本 HTML 粘贴不再由 MDPad 的 sanitizer、`pasteHTML()` 或 Markdown fallback 主动接管。
- 当剪贴板包含 `text/html` 时，交给 ProseMirror/Tiptap 原生 paste 处理。
- 只有剪贴板没有 `text/html` 且纯文本明显是 Markdown 时，才调用官方 Markdown 插入。
- 表格主链路切换到 Tiptap 3 官方 `TableKit.configure({ table: { resizable: true } })`。
- 图片文件粘贴保留附件库流程，但收敛为独立的 image-file paste extension。

## Documentation
- `README.md` / `README_zh.md` 已更新到 v0.2.11 版本亮点。
- 新增 `docs/release-notes-v0.2.11.md`，记录安装包、SHA256、验证结果与已知边界。

## Verification
- `pnpm install`
- `pnpm exec tsc --noEmit`
- `pnpm exec vitest run src/features/editor src/shared/utils/appToastOverrides.test.ts`
- `pnpm build`

## Known Boundaries
- 复杂 HTML 粘贴优先目标是保持原生 paste 路径稳定，不再通过旧 sanitizer 主动改写结构。
- 后续若要恢复更强的表格浮动菜单或邻列联动 resize，应作为 Tiptap 3 TableKit 之上的 UI 层增量实现。
- 建议继续用真实 ProseMirror/Tiptap 来源页面做桌面粘贴手工验收，确认系统剪贴板 payload 与测试环境一致。
