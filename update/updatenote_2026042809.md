# v0.2.11 更新记录

## Summary
- 参考 `new_envdama_ui` 的实际实现，重新调整 MDPad 的 Tiptap/Markdown 主链路。
- 编辑器内部恢复为 HTML/Tiptap doc 状态，Markdown 只作为文件读取与保存边界格式。
- `tiptap-markdown@0.8.10` 保留截图同款配置，但不再作为 MDPad 文件保存的主 serializer。

## Paste / Markdown
- 打开和外部同步时，先用现有 `markdownCodec.markdownToHtml` 把 Markdown body 转为 HTML，再交给 Tiptap。
- 保存同步时，基于 `editor.getHTML()` 走现有 `htmlToMarkdown`，不再优先调用 `editor.storage.markdown.getMarkdown()`。
- HTML 富文本粘贴在媒体/图片 pipeline 未处理后，简单 HTML 继续交给 ProseMirror 默认 paste。
- 对复杂表格、Office/Google、外部 wrapper 等高风险 HTML，raw paste 阶段会先走现有 sanitizer/fallback，避免 `Position ... outside of fragment` 继续冒泡。
- 纯 Markdown 文本粘贴与复制仍保留 `Markdown.configure({ html: true, transformCopiedText: true, transformPastedText: true })` 的能力。

## Tests
- 更新 `tiptapMarkdownIntegration` 测试，覆盖 Markdown 文件边界、HTML 默认 paste，以及复杂标题/表格内容连续粘贴两次后的 doc 合法性。
- 新增默认 HTML paste 抛 `Position ... outside of fragment` 时降级纯文本的回归断言。
