# 2026-04-28 14:xx 全量采用 new_envdama_ui 粘贴架构

## 背景
- 用户确认从 ProseMirror 页面把 Markdown 渲染内容粘贴回 MDPad 仍会触发 `Position ... outside of fragment`。
- 本轮不再继续为 sanitizer、diagnostics 或 `pasteHTML()` 接管补丁，而是清理所有自研 TipTap paste 分支。

## 本轮调整
- `MarkdownEditor` 不再提供全局 `paste` / `handlePaste` 处理器；富文本 HTML 由 Tiptap/ProseMirror 默认粘贴链路处理。
- 移除旧 `clipboardPipeline`、rich HTML sanitizer paste、paste diagnostics、自研 Markdown paste handler 和 Markdown image paste handler。
- 保留 `Markdown.configure({ html: true, transformCopiedText: true, transformPastedText: true })`，让 `tiptap-markdown` 负责 Markdown 文本增强。
- 参考 `new_envdama_ui` 的 FileHandler 思路，新增本地 `ImageFilePasteExtension`：只处理剪贴板中的 `image/*` 文件，写入附件库后插入 `resizableImage`。

## 验收重点
- 复杂富文本、表格、网页/ProseMirror 内容粘贴不再进入 MDPad 自研 paste fallback。
- 图片文件粘贴仍能保存到附件库并插入编辑器。
- Markdown 文件打开/保存仍保持 HTML-first 编辑状态与 Markdown 文件边界。
