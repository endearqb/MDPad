# 自动折叠标题栏与底栏

## 背景
- 缩小窗口宽度时，自绘标题栏和底栏的固定按钮/文字会相互挤压。
- 本次不提高 `420px` 最小窗口宽度，改为建立响应式折叠层级。

## 变更
- 标题栏新增更多操作菜单，窄窗口下折叠文档视图切换与明暗主题切换。
- 底栏新增状态选项菜单，窄窗口下保留保存状态与字数，编码、外部变更模式、示例、语言、Markdown 样式和 UI 样式转入菜单。
- 样式新增 `640px` 与 `520px` 两级响应式规则，修正文件名、重命名输入和底栏文本的收缩策略。
- 补充 TopBar 与 StatusBar 的折叠菜单交互测试。

## 验证
- `.\\node_modules\\.bin\\tsc.cmd --noEmit` 通过。
- `pnpm build` 通过。
- `git diff --check` 通过，仅提示部分文件下次 Git touch 时 CRLF 会转 LF。
- 定向 Vitest 启动时遇到 Vite config 的 esbuild `spawn EPERM`；自动提权审核超时，本轮未能在当前沙箱内完成该测试命令。
